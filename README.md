## ▶️ Running a Solution

Ensure that Python 3 is installed on your system.

Clone the repository:

```bash
git clone https://github.com/CoderMaeraj/LeetCode-Solutions
```

Navigate to the repository:

```bash
cd LeetCode-Solutions
```

Run an individual solution:

```bash
python Python3/0001-0100/0001-Two_Sum/0001-two_sum.py
```

Replace the file path with the solution you want to run.

Some solutions use LeetCode's expected class and method signatures and may require a test harness or sample input to run independently.
